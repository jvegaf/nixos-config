# OpenCode Wrapper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the complete OpenCode setup from `nixdots` into this flake and expose one reproducible `nix run .#opencode` package, including local AI tooling, external `superpowers`, and all Matt Pocock skills.

**Architecture:** `modules/features/opencode` will own shared OpenCode settings and generated Markdown resources. A Nix derivation will assemble those resources plus the read-only `skills/` subtrees from the `superpowers` and `mattpocock/skills` inputs into an immutable `OPENCODE_CONFIG_DIR`; the wrapper will provide the JSON config, runtime LSP packages, and both environment variables. The Home Manager output will install the same wrapped package rather than configure `programs.opencode` separately.

**Tech Stack:** Nix flakes, flake-parts, `nix-wrapper-modules`, Home Manager, OpenCode, `numtide/llm-agents.nix`, generated Markdown/YAML frontmatter, Git inputs.

**Spec:** `docs/superpowers/specs/2026-09-12-opencode-wrapper-design.md`

## Global Constraints

- Preserve the existing `nixdots` permissions, LSP definitions, plugins, commands, agents, skills, and context behavior.
- Include the complete upstream `mattpocock/skills` set, but expose only its `skills/` subtree under `skills/matt-pocock/engineering` and `skills/matt-pocock/productivity`.
- Do not execute `setup-matt-pocock-skills` automatically and do not copy upstream repository metadata, plugin manifests, or package files.
- Keep the config directory immutable and put runtime state in OpenCode's normal state/cache/data locations.
- Support the destination flake's declared systems: `x86_64-linux`, `aarch64-linux`, and `aarch64-darwin`.
- Do not configure `programs.opencode` in Home Manager; install the shared wrapper package through `home.packages`.
- Use `flake.lock` to pin every Git input; do not hand-edit the lock file.
